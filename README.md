# Sound Identity: music branding studio

Landing page per uno studio di music branding (sonic logo, musica per campagne, sound in store), con un **Sonic Logo Lab** interattivo: scegli il carattere del brand e il browser suona una bozza di firma sonora con la Web Audio API.

**Demo live:** https://tahabahousse.github.io/music-branding-studio/

## Cosa contiene
- Hero con equalizzatore animato in CSS
- Servizi e processo di lavoro
- Sonic Logo Lab: 4 caratteri (energico, elegante, affidabile, giocoso), ognuno con note, timbro e ritmo propri
- Contatto via email

## Tecnologie
HTML, CSS, JavaScript e Web Audio API, nessuna dipendenza. Pubblicato con GitHub Pages.
